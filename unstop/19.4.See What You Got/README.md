> ## Problem Statement

Given three integers A, B, and C, find a number X such that A xor X = B and C.

> ## Input Format
```
The first line contains a single integer T, representing the number of test cases.

The first line of each test case contains three space separated integers A, B and C. 
```

> ## Output Format
```
For each test case, print the value of X in separate line.

```

> ## Constraints
```
1 ≤ T ≤ 10

0 ≤ A, B, C ≤ 2⋅10^9

```


> ## Sample Testcase 0

**Testcase Input**
```
1  
8 2 3
```
**Testcase Output**
```
10

```
**Explanation**

Here A=8, B=2 and C=3.


8 XOR 10 is equal to 2 AND 3 = 2. 


Hence the value of X is 10.

---

> ## Sample Testcase 1

**Testcase Input**
```
1 
5 1 6
```
**Testcase Output**
```
5
```
**Explanation**

Here A=5, B=1 and C=6.


5 XOR 5 is equal to 1 AND 6 = 0.


Hence the value of X is 5.
